자동차 경주 게임

객체
1. 자동차

입력 (유저)
- [ ] 이름을 입력할 수 있다.
- [ ] 몇번 이동할 것인지 입력할 수 있다.
- [ ] 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.

출력
- [ ] 안내 문구를 출력할 수 있다.
- [ ] 자동차 이름을 출력할 수 있다.
- [ ] 자동차 이름별 전진 횟수를 출력할 수 있다.
- [ ] 우승자를 안내할 수 있다.
- [ ] 예외 상황 시 에러 문구를 출력할 수 있다.
- [ ] 에러 문구는 [ERROR] 로 시작해야 한다.
- [ ] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.


검증
- [ ] 이름이 5자를 초과할 수 없다.
- [ ] 시도 횟수는 숫자여야 한다.

처리
- [ ] 한 라운드에는 모든 자동차가 움직인다.
- [ ] 그 라운드를 입력한 횟수만큼 반복한다.
- [ ] 라운드 종료 후 가장 많이 이동한 차를 우승자로 결정한다.
- [ ] 자동차 이름을 쉼표로 구분할 수 있다.
- [ ] 전진 입력에 대해 0~9중 무작위 값을 만들 수 있다.
- [ ] 무작위 값이 4 이상인 경우 전진한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`를 발생시킬 수 있다.
